# LLM agent as an investment analyst — forward test on the Dow Jones 30

Master's thesis project (Data Science and Business Analytics, Faculty of Economic Sciences, University of Warsaw).

A weekly forward test (6 Dec 2026 – 21 Jun 2027): Claude Opus 5.5 with and without web search ranks the 30 Dow Jones stocks each week and buys the top 4; results are compared with XGBoost, an equal-weight 1/N portfolio and DIA. Main metric: weekly rank information coefficient (IC).
